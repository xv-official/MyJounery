    💾 数据管理
    备份为 JSON 文件，可分享或保存到云盘；恢复会覆盖当前数据。
    🔔 通知提醒
    到点自动弹出系统通知，App 关闭也能提醒。
    ⚠️ 国产手机必看
    点击上方按钮开启通知后，还需手动关闭电池优化：
    小米/红米：设置 → 应用管理 → 日程管理 → 省电策略 → 无限制
    华为/荣耀：设置 → 电池 → 应用启动管理 → 日程管理 → 允许自启动
    OPPO/vivo：设置 → 电池 → 日程管理 → 允许后台运行
    否则手机会杀后台，关闭 App 后通知不弹出。
